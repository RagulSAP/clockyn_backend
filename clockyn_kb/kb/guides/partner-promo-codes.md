A partner promo code comes from a Clockyn partner, for example a YouTube, Instagram or Facebook channel that recommends Clockyn. It looks like a friend's referral code: 6 letters and digits. If you registered with one, you get a discount on a Prime or Elite plan.

## Where to enter a partner promo code

You can enter the code only while you register. It cannot be added to a company that already exists.

1. Open the Clockyn app, choose **Admin Portal**, and start **Register Company**. See [Getting started: register your company](kb:getting-started-register-company).
2. In the optional **Referral code** box, type the code. Capital and small letters both work.
3. When the code is right, the screen shows **Referred by**, then the channel name and the discount, in the form `Referred by (channel name) - (percent)% off Prime and Elite`.
4. Finish registering as usual.

The partner never sees your company's data. The Referral code box takes one code. You cannot use a friend's referral code and a partner promo code together. Decide which to use before you register.

## How much discount you get

The discount percent is set for each code, so different partners can give different discounts. You see the percent on the register screen when you enter the code, and again on Settings > Refer & Earn and on the Payment Summary.

It works like a friend's reward:

- It can be used **once**, on your first plan after the free trial or on a renewal.
- It works on **Prime and Elite** only.
- It cannot be combined with a coupon on the same purchase.

See [How Refer & Earn works](kb:refer-and-earn) for how to apply a reward on the Payment Summary.

## How long the discount is valid

A code can have a validity period. If it does, your discount is valid for a set number of days after you sign up. Settings > Refer & Earn shows **Valid until** with the date. After that date the reward shows as **Expired** and cannot be used. If no date is shown, the reward does not expire.

## Common questions

### Why does my promo code say it is not valid?
The register screen shows "This referral code is not valid" when the code cannot be used. Check these:

1. A code has exactly 6 characters, letters and digits only, with no spaces.
2. Look-alike characters are easy to mix up, for example the digit 0 and the letter O, or the digit 1 and the letter I.
3. The code may have been switched off by the partner or by Clockyn.
4. The code can only be entered while registering, not after your company is created.

If the code is still refused, ask the person who gave it to you to confirm it, or contact support.

### Why was my reward not applied, or why does it show Expired?
Check these:

1. It has expired. Settings > Refer & Earn shows Expired when the validity days after your sign-up have passed.
2. You picked the Core plan. The reward works on Prime and Elite only.
3. You are adding staff with Upgrade Plan. The reward works on a first plan or a renewal only.
4. You already applied a coupon. Use either a coupon or a reward, not both.
5. The reward was already used on an earlier payment.

The reward card on the Payment Summary says which one applies.

### Can I use a friend's referral code and a partner promo code together?
No. The Referral code box takes one code, and a code cannot be added or changed after your company is created. Your own referral code is separate: after you register you can still share it.

### Can I enter the code after I registered?
No. The code can only be entered on the register screen.

### How can my business or channel become a Clockyn partner?
If you run a YouTube, Instagram or Facebook channel, or have another audience, and want to recommend Clockyn, write to us. Open the Support tab and send a message in **Live Chat** with your channel name, its link and your contact details. The Clockyn team will explain the partner programme and, if you are accepted, give you your own code. Every company that registers with your code gets a discount on Prime or Elite.

## What can go wrong

| Symptom | Likely cause | What to do |
| --- | --- | --- |
| "This referral code is not valid" | Typo, look-alike characters, or the code is switched off | Check the 6 characters and ask the person who gave you the code |
| Reward shows Expired | The validity days after sign-up have passed | Contact support if you think it should still work |
| Apply is greyed out | Core plan, Upgrade Plan, or a coupon is applied | Read the reason on the reward card |

## When to contact support

If your reward expired before you could buy and you think it should still work, or your code is refused, ask in Support > Live Chat. Have these ready:

- Your company name and admin e-mail
- The promo code and your sign-up date
- A screenshot of Settings > Refer & Earn or the register screen
